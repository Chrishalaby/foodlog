# Security

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button on this repository's
Security tab, not in a public issue.

Include what you found, how to reproduce it, and which version or commit you tested (`GET /api/health` shows it).
Fixes ship in a new release, and the report is credited unless you ask otherwise.

Only the latest release is supported. Self-hosters should update with `git pull` and `docker compose up -d --build`.
